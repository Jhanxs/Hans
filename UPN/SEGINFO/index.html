Guía de Instalación de Ubuntu Server 26.04 LTS

Documentación paso a paso para el despliegue de un servidor Ubuntu en un entorno virtualizado utilizando VirtualBox.

Paso 1: Preparación del Entorno

Descargar la imagen ISO oficial de Ubuntu Server 26.04. En VirtualBox, crear una nueva máquina virtual asignando tipo "Linux" y versión "Ubuntu (64-bit)". Asignar un mínimo de 2048 MB de RAM y crear un disco duro virtual de 25 GB con reserva dinámica.

Paso 2: Arranque e Idioma

Montar el archivo ISO en la unidad óptica de la máquina virtual e iniciarla. En el primer menú, seleccionar Try or Install Ubuntu Server. Posteriormente, definir el idioma del instalador en English para mantener estándares de administración.

Paso 3: Configuración de Teclado y Red

Seleccionar la disposición del teclado. En caso de usar teclado con distribución internacional en el equipo anfitrión, seleccionar la variante English (US, intl., with AltGr dead keys). En el apartado de red, mantener la interfaz con la asignación automática por DHCP (modo NAT en VirtualBox).

Paso 4: Particionamiento de Disco

Dejar los apartados de Proxy y Mirror por defecto. En la configuración de almacenamiento, seleccionar Use an entire disk asegurándose de elegir el disco virtual de 25 GB. Confirmar la estructura de particiones (LVM) y seleccionar Continue en la advertencia de formateo.

Paso 5: Credenciales y Servicios

Llenar los datos del perfil del servidor: nombre de visualización, nombre del equipo (hostname), usuario administrador y contraseña segura. En la pantalla de configuración de SSH, marcar la opción Install OpenSSH server con la barra espaciadora para habilitar conexiones remotas.

Paso 6: Finalización

Omitir la instalación de paquetes Snap adicionales. Esperar a que el proceso de instalación y actualización finalice. Seleccionar Reboot Now, presionar Enter cuando el sistema solicite retirar el medio de instalación y loguearse con las credenciales creadas.
